# TODO Tracker

> This file links to the live `TODO.md` at the repository root, which is the single source of truth for in-flight work.

See [`../../TODO.md`](../../TODO.md) for the current Open / In Progress / Done lists.

Per-Task Briefs live in [`../../todos/`](../../todos/) (one Markdown file per Task ID).

## Quick reference

- **Open** — work not yet started; carries an `assigned_to` and a `target milestone`.
- **In Progress** — active Tasks with a linked branch / PR.
- **Done** — completed Tasks, kept for audit trail.

The Director is the sole writer of `TODO.md` and updates it at every dispatch and completion event.
